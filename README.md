# Brío

Rutinas de ejercicio para personas mayores, en casa o en el gimnasio.

- **Preparar una rutina**: eliges los minutos y el lugar y la rutina sale al momento, con la duración exacta.
- **Modo avanzado**: eliges cada ejercicio, las series y las repeticiones.
- **Mis rutinas**: se guardan en el navegador y se pueden pasar a otra persona con un código.
- **Entrenar**: foto animada de cada ejercicio, explicación breve, temporizador y voz opcional.

Web estática (HTML, CSS y JS sin dependencias). Para probarla en local:

```bash
python -m http.server 8000
```

Comprobación del generador de rutinas: `node check.js`.

Fotos de los ejercicios: [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (dominio público).
